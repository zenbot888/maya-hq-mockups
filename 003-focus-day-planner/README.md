## Variant: Focus Day Planner

### Design stance
A ritualized daily planning screen that starts with capacity and protects Paris’s nervous system.

### Key choices
- Layout: editorial hero + capacity card + action list + timeline
- Typography: serif headline with clean sans-serif interface details
- Color: paper, warm blush, ink, subtle terracotta
- Interaction: capacity selector, tabs, toast confirmations

### Trade-offs
- Strong at: daily grounding, time-blocking, reducing overwhelm
- Weak at: less suited to broad project management or large task volumes

### Best for
The morning planning ritual: choose capacity, select Top 3, protect focus, and generate a realistic day.
