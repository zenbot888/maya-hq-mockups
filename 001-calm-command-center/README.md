## Variant: Calm Command Center

### Design stance
A soft, elegant daily HQ that makes Paris feel clear within five minutes.

### Key choices
- Layout: sidebar + main dashboard
- Typography: modern system sans-serif
- Color: warm neutrals, cream, cacao, soft amber
- Interaction: Brain Dump modal with a visible sorting result

### Trade-offs
- Strong at: emotional calm, daily clarity, founder-friendly flow
- Weak at: less powerful for managing many moving cards at once

### Best for
Paris opening Maya HQ every morning and immediately knowing the Top 3, pings, calendar blocks, wellness anchor, and what not to touch.
