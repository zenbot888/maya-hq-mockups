## Variant: Visual Kanban HQ

### Design stance
A sharper project operating board for moving multiple workstreams without losing the big picture.

### Key choices
- Layout: horizontal kanban lanes: Now, This Week, Waiting On, Parking Lot
- Typography: modern sans-serif, high contrast
- Color: dark executive board with amber priority signals
- Interaction: click cards to open a detail drawer

### Trade-offs
- Strong at: scanning many actions, separating now/later/waiting, founder operator mode
- Weak at: can feel more intense and less emotionally soft

### Best for
Weekly planning, Awaken operations, sponsor/vendor pipeline work, and project triage.
